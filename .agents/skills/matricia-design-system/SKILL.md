# Design system
- **Scope:** tokens, typography, spacing, components, layouts, feedback and cross-space visual consistency.
- **Invariants:** Version A is mandatory; shared primitives precede duplication; all interactive states are real; critical paths work from 360 px; visual polish never replaces backend behavior.
- **Targeted context:** load tokens, affected primitives, canonical screen spec and nearby usage; avoid unrelated screens.
- **Checks:** responsive breakpoints, keyboard/focus, contrast, labels, loading/empty/error/forbidden states, FR/AR expansion, RTL mirroring and visual regression.
- **Ownership:** one writer for each shared primitive/token file; consumers coordinate before changing contracts.
- **Handoff:** report components/tokens, screenshots or evidence, checks/tests and accessibility risks.
