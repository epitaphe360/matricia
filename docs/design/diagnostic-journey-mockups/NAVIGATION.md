# Navigation fonctionnelle

```text
00 Question publique
  -> 01 Récapitulatif
  -> 02 Analyse en cours
  -> 03 Résultat indicatif
       -> 04 Détail d'une priorité
            -> 05 Enregistrer le bilan / connexion
                 -> 06 Mes diagnostics
                      -> 13 Diagnostic complet / questionnaire
                      -> 07 Analyse détaillée versionnée
                           -> 08 Détail constat et recommandation
                                -> 09 Solutions adaptées
                                -> 10 Revue humaine
                                -> 12 Transformer en besoin
                           -> 11 Évolution

Variantes transversales :
  14 États honnêtes sans conclusion forcée
  15 Arabe RTL
  16 Mobile public
  17 Erreurs et reprise
```

## Destinations produit

| Action | Destination |
|---|---|
| Modifier mes réponses | Étape publique ou questionnaire Client concerné |
| Enregistrer mon bilan | Authentification puis organisation autorisée |
| Voir mon analyse | Analyse versionnée du diagnostic sélectionné |
| Comprendre le résultat | Détail, preuves et méthode applicables |
| Voir les solutions | Solutions internes adaptées au contexte confirmé |
| Me faire accompagner | Demande de revue humaine liée au diagnostic |
| Passer à l'action | Plan d'action ou transformation en besoin |
| Décrire mon besoin | Brouillon de demande prérempli, jamais envoyé sans confirmation |
