# Matricia — maquettes du tableau de bord Franchisé

Ce dossier centralise toutes les maquettes et la navigation de l’espace Franchisé.

## Règle de périmètre

- Le franchisé voit exclusivement sa bibliothèque mandatée.
- Il ne peut ni consulter ni rechercher les autres bibliothèques.
- Services, catégories, questions, questionnaires et règles sont toujours filtrés côté serveur par le mandat actif.
- Le franchisé prépare des brouillons FR/AR, simule, puis soumet à Matricia.
- Matricia valide ou demande une correction avant publication.
- Le Client répond uniquement aux questionnaires publiés et validés.
- Une version publiée est immuable ; toute évolution crée une nouvelle version.
- Les libellés « Exemple illustratif » des PNG sont des placeholders Figma : le produit utilise des données réelles ou démo métier, jamais ce libellé.
